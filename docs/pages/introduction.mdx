:::note{title="Soundtrack"}
The cabinet opens with an **ENTER** gate at `/`. That gesture unlocks browser
audio, starts **"You The One For Me"** (the R4 intro), then hands over to the
active game's playlist. Every refresh returns to ENTER. Changing the GAME
selector changes the soundtrack and the whole page theme. Details:
[Music player](/play/music).
:::

## The short version

1. **Race entry:** open `/`, press **ENTER**, land in **WELCOME TO RIDGE CITY**, then open **GAMES** and start **Ridge Racer Type 4** (or check its disc deck first). The first load is the 341 MB R4 CHD; afterwards it comes from cache.
2. **LAN 2P:** both machines press **2P** in the shell top bar, one creates a four-character room, the other joins, both press **READY**. The shell loads `/play-net` with the rolled plan; relay on TCP 3010.
3. **Native:** run `Ridge_Racer_4_Recompiled.exe --no-launcher --bios ... --disc ...`, or use `Play Ridge Racer 4.bat` in the project root. The old lobby at `/lobby` is the host-stream fallback.
4. **Verify:** `/api/status` on the host shows the LAN URLs and cabinet state. It
   does not include relay state; check relay health at `:3010/health`.
